# The XYZ Method for Resume Bullets - Quick Guide

The XYZ method is a resume writing formula recommended by Google recruiters that transforms vague job duties into quantifiable achievements. It follows this structure:

**"Accomplished [X] as measured by [Y] by doing [Z]"**

- **X** = What you accomplished (the outcome or improvement)
- **Y** = How you measured success (numbers, percentages, time saved, dollars)
- **Z** = How you did it (specific actions, tools, or methods you used)

**Example:**
Instead of: "Managed social media accounts"
Write: "Increased social media engagement by 35% by creating and posting IG Reels and TikTok content daily"

**Key principles:**
- Start every bullet with a strong action verb
- Always include a metric (even estimates like "approximately 20%")
- Keep each bullet to one line when possible
- Focus on outcomes, not just responsibilities
